# PDF 作品集

這個資料夾放可下載的 PDF 版本。repository 是公開的，放在這裡的檔案任何人都下載得到。

## 放進來之前

- 只放「網頁版」：每頁轉成圖片再組回 PDF，隱藏圖層、圖框裡的電話等文字都不會留下。
- 原始 Illustrator 輸出檔（含隱藏文字、檔案很大）留在自己電腦或 Google Drive，不要放進來。
- 單檔建議 10 MB 以內（GitHub 上限 100 MB，超過 50 MB 會警告）。

## 命名

`年-月_領域_專案.pdf`，例如 `2026-11_interior_banqiao-studio.pdf`。舊版不用刪，新版用新的日期。
